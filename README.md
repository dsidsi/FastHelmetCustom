【内容】
· FAST MT Gen2 战术头盔 ×2（沙色 / 黑色）
  - 5 级防护，购买即预装 Gen2 顶部/后颈装甲板
  - 新增专用侧甲挂点（mod_equipment_003），面罩槽/侧甲槽各司其职
  - 可同时佩戴：面罩 + 护颚 + 侧甲 + 顶板 + RAC 耳机
  - 人机/转向惩罚为原版的一半
· Gen2 配件 ×4（Peacekeeper 美商 4 级忠诚，美元结算）
  - 面罩（5 级）、侧甲（5 级，自带护颚子槽）、护颚（5 级）、顶板（6 级）
  - 惩罚同样减半；内置装甲板不单独出售（与原版一致）

【特点】
- 新物品全部由 mod 在服务端内存中克隆原版数据生成，不修改游戏原文件
- 支持简体中文 / English（随客户端语言自动切换）
- Fika 联机兼容：主机装完整 mod，队友只需客户端插件（FastHelmetClient.dll）

【安装】
解压到 SPT 游戏根目录（与 EscapeFromTarkov.exe 同级），SPT 与 BepInEx 文件夹自动合并，重启服务端与客户端即可。

【卸载】删除 SPT/user/mods/FastHelmetCustom 与 BepInEx/plugins/FastHelmetCustom 两个文件夹。

【兼容】SPT 4.0.x（4.0.13 实测），BepInEx 5。
